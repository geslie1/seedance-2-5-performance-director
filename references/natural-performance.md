# 细微表情与自然度修复

用于近景表演、内外反差、笑哭过渡，以及“太假、表情僵、塑料感”的具体诊断。先确定是反应缺少前因、表情没有过程、变化看不见，还是身份与材质不稳定，再处理对应问题。以下是创作选项，不是用表情识别真人心理的工具。

按需阅读：第 1 节用于强度选择，第 2–3 节用于表情过程与词语，第 4–5 节用于镜头、声音和约束，第 6 节用于修复已有提示词或成片。

## 1. 三个维度分别设计

| 维度 | 要决定什么 | 怎样落到表演 |
| --- | --- | --- |
| 感受强度 | 事件对这个人有多大影响？ | 影响注意力、任务推进或接话方式，不直接等于脸动多大 |
| 外显幅度 | 此刻允许观众看到多少变化？ | 从继续原动作，到一次明确停顿，再到大幅动作；按风格和景别选择 |
| 控制意图 | 是否在管理自己的表达？为了什么、给谁看？ | 维持礼貌、延后回应、成功收住或放弃掩饰；没有掩饰需求时直接表达 |

同一条好消息，可以让坦率的人立即笑着分享，也可以让正在主持会议的人先把议程说完。两种都可能感受强烈。低／中／高只帮助比较本场前后，数字不是可执行参数；不计算“真实感分数”。

只有剧情需要时才写控制的变化：维持 → 短暂露出 → 重新收住，或维持 → 决定直接表达。也可以一直维持成功。不要从“高压力”自动推导眼角抽动、吞咽或发抖；观众可以通过已知处境和行为选择理解人物。

## 2. 让一个表情具有时间过程

对关键变化，选择需要的环节：

`已有状态 → 触发到达 → 变化开始 → 维持／修正 → 消退或残留`

这里描述的是表情自身怎样变化；事件顺序和他人反应仍按主流程的因果链安排。无须每个微动作走完整套，也不把时长等分。

- **已有状态**：正在微笑、正常说话、专心看文件。不要每次都从“空白脸”开始。
- **变化开始**：选择一个能看清的起点，例如听到最后一个关键词后，原本舒展的嘴角缓缓收回。正常同步反应也成立，不规定身体或眼睛必须先动。
- **维持或修正**：人物仍在确认答案、保持礼貌或继续说完一句话；维持的理由来自任务。静止可以成立，无须用随机眨眼证明“活着”。
- **消退或残留**：直接喜悦可在笑过后恢复交谈；克制的伤心也可以继续影响下一句的接话时机。残留不必总在脸上，更不能强制回到微笑。

复合情绪依靠顺序或分工变得可读。例如收到拒绝后仍想礼貌道别，可以先把话说完，再让笑意退去；若关系和风格适合，也可以笑着承认失望。不要同时下达“嘴唇紧闭、笑出声、说清长句”三条互斥动作。

## 3. 用普通动作词选择局部信号

下表是候选表达，不是情绪对应表。默认用普通中文，不必带 AU 编码、肌肉名或无依据的小数角度。每拍只选服务信息的少数信号；已靠任务动作说明变化时，可以完全不加脸部细节。

| 部位／通道 | 可用的变化写法 | 适用与检查 |
| --- | --- | --- |
| 视线 | 从递来的物件移到说话者脸上；多看一拍后回到原任务 | 必须有目标；用注意力转移替代“瞳孔失焦”“眼里结冰” |
| 上眼睑 | 在看清结果后略抬起，随后回到自然开合 | 适合近景的注意变化；不能单独证明惊喜或恐惧 |
| 眉间 | 原本收紧的眉间在确认后松开；只在核对时稍收紧 | 起点明确；不与“眉眼全程不动”同时使用 |
| 嘴角 | 笑意开始出现、停在较小幅度、随后自然退去 | 写一个连续过程，避免全程保持同一弧度；单侧起动可选 |
| 双唇 | 准备开口后合上；说完才短暂抿住，下一句前放松 | 给发声留空间；不要把持续咬唇当通用情绪信号 |
| 下颌 | 一句话结束后稍收紧；重新开口前松开 | 不与整段紧咬牙、清晰流畅说话冲突，不需逐块指定肌肉 |
| 眼周／泪光 | 若已经设定眼眶湿润，眨眼后仍保留湿润状态 | 流泪有铺垫；接续姿态和重力方向，不要求瞬间凭空泛红 |
| 呼吸／接话 | 回答前一次轻呼气；原本利落的答句晚一拍才接上 | 自然呼吸可维持不变，不用每个情绪节点都屏息或喘气 |

不把瞳孔大小当普通镜头里可靠的情绪开关，不把眨眼、单侧微笑或避开目光视为撒谎或真心的证据。无需为“真人感”额外加入毛孔、汗液、眼泪和肌肉名；这些也不能替代成立的表演。

## 4. 让镜头读得到，让声音听得见

- 中远景先用朝向、步速、距离、重心和任务中断。细小嘴角变化若承担关键情节，要有能读到它的构图；否则换为可见行为，不叠加更多肌肉指令。
- 近景也要检查遮挡和焦点。头发、手、杯子挡住嘴部时，可以让眼神或放下杯子后的变化承担信息；不要同时要求遮脸和完整看清下半张脸。
- 表情变化发生时保留观察机会。推近是可选的，稳定镜头也可以；持续跟拍若承担空间信息，可以继续，不强制“情绪节点一到就停镜头”。
- 先写发声动作，再写声音大小。近距离安静室内可能听见一次呼气，远处嘈杂街道不应凭空放大吞咽。若用户指定主观音效，标清它是声音设计。
- 环境声帮助建立空间，不必每段列满。停对白不等于环境声全部消失；只有明确声音设计时才抽掉底噪。

## 5. 稳定身份，不冻结表情

限制应针对具体失败，并允许正常变化。先用正向句说明期望，再按需补充少数限制；没有相关问题就不填满清单。

| 容易互相抵消的写法 | 更合适的限定 |
| --- | --- |
| 五官位置全程恒定，面部不能变化 | 保持同一人的脸型与五官识别特征，允许眉眼、嘴部随表情正常运动 |
| 全程微笑、自然笑起又收回 | 初始带笑；听到答复后笑意减弱，结尾停在较轻的弧度 |
| 禁止任何夸张表情 | 按用户要求限定本场幅度；喜剧或外放人物仍可明确表达 |
| 表情绝对稳定、不要抖动 | 避免身份和结构跳变，保留有原因的短暂颤动或动作变化 |
| 情绪复杂、无数微表情不断闪过 | 指定关键刺激和一个主要变化，给其出现、维持或收回的空间 |

需要镜面、触碰、持物的场景，只补相应的倒影、接触和道具连续性约束。不要把参考资料里的“至少五条负面词”当成要求，也不承诺添加限制就能修复所有生成问题。

## 6. 按症状做最小修复

| 观察到的问题 | 先检查什么 | 优先改什么 |
| --- | --- | --- |
| 面瘫、反应缺失 | 是否有角色接收到的触发？是否锁死了脸？ | 保留任务，增加一个明确接收和行为变化；解除冲突约束 |
| 从笑脸瞬间变哭脸 | 是否只列两个静态情绪，缺乏中间行动？ | 写清理解或控制的一个过程；用户要求骤变时保留骤变 |
| 表情很多仍显假 | 是否同拍安排了太多通道和无目的抽动？ | 删除重复信号，留下一个主要变化及其时间过程 |
| 每句都屏息、每拍都抿嘴 | 是否把素材词库当成必做清单？ | 恢复顺畅日常基线，只在关键刺激处改变节奏 |
| 细微表情看不见 | 是否远景、逆光、遮挡，或变化一发生就切走？ | 调整观察机会；景别锁定时换为轮廓或任务动作 |
| 笑容一直挂着 | 是否只有“保持微笑”，没有后续任务？ | 写明何时维持、何时自然减弱或恢复交谈，不强制立刻收笑 |
| 切镜后状态清零 | 下一段是否重新写成初始表情？ | 承接前段的笑意、湿润眼眶、接话节奏或未完成动作 |
| 塑料质感、身份漂移 | 问题发生在材质／身份还是反应过程？ | 若属外观问题，检查参考冲突和外观约束；不靠增加眨眼修复材质 |

只拿到提示词时，这些是文本风险，不能说已经观察到成片缺陷。有视频时才核对连续动作与音画；单张截图无法证明反应时机或节奏僵硬。一次失败也不足以确定是哪条提示词导致。

局部优化先保留剧情、台词、道具和结尾，只修正问题所在的反应链及必要接续。用户要求试生成时，每轮优先改变一个主要因素，方便比较；是否提交和重试仍由当前任务授权及平台条件决定，不自动生成付费视频。
