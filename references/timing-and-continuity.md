# 时间预算与连续性校核

此文件中的字速、停顿与动作时长是粗排练习的起点，不是官方参数、通用生理定律或模型能力保证。优先按具体台词、动作距离和表演风格做估算；具备实际朗读或排练记录时再据其修正。

## 1. 区分三个量

- **目标成片时长 T**：用户希望观众看到的总长度。
- **设计占用时长**：台词、动作、反应与镜头衔接在时间轴上实际占据的长度。
- **平台单次生成限制**：只有需要适配或执行时才核实，不能从 T 推导出来。

任何纯文字校核都只能判断“设计大致可演”，不能证明实际生成一定按时完成。

## 2. 先估台词，不按句数平均

中文短对白可先以这些粗略范围起排：

| 语态 | 起排参考 | 需要另留的时间 |
| --- | --- | --- |
| 快速短句、熟人拌嘴 | 约 4–5 个发音音节／秒 | 接话、强调词、突然中断 |
| 日常清晰说话 | 约 3–4 个发音音节／秒 | 句中停顿、转向听者 |
| 迟疑、压低声音、强情绪 | 约 2–3 个发音音节／秒 | 呼吸、改口、情绪阻塞 |

以实际发音估算：普通汉字通常可粗略当一个音节，数字、英文、缩写、多音节外来语应先按读法展开。标点不算音节，但可能占停顿。

`一句台词估时 ≈ 发音音节数 ÷ 计划语速 + 可听停顿`

例如“手机给我”有约四个音节，快速读出或许只需约一秒；人物转向、伸手、等回应并不自动包含在这一秒里。

旁白同样占声音时间，不能用旁白把本来需要观众观察的反应解释掉。多人抢话只在剧情确需且清晰度允许时设计，不作为压缩长对白的默认工具。

## 3. 先后关系决定预算

把关键事件标成**串行**或**可并行**：

- 串行：看清物件 → 理解信息 → 改变决定 → 执行动作，原则上相加。
- 可并行：说一句简短的话时把杯子放稳，或听对方说话时停止翻页；真正同时发生的部分按最长占用估计。
- 部分并行：手先伸出，接近物件时说话，话说完后等对方松手；只扣除重叠的那一段。
- 互斥：喝水时清楚说长句、转头背向对方却持续正面凝视、两手忙碌时无支撑接第三件物品，需要改写。

一个粗略的关键路径表达是：

`节拍占用 ≈ 前置串行动作 + max(真正同时发生的动作、台词等) + 后续串行反应`

不要对整段所有行为直接取最大值。不同人物的轮流台词相加，依赖上句意义的反应不能提前完成。已经计入的停顿只计一次，避免既加在台词里又作为独立反应重复相加。

## 4. 先给转折和余韵留位

动作能够并行，不代表关键信息能够同时被观众读懂。粗排时分别标出两条线：

- **表演线**：台词、动作、对方反应各自的先后与真正重叠部分。
- **观看线**：观众此刻应看谁、辨认哪条变化，景别是否足够，切镜或焦点转移后能否接上前因。

例如，四秒大全景可以容纳多人后退与远处舞动，却未必能让观众同时认出某人的嘴角变松、另一人的握力改变。把必要微表情交给可读的近景，大全景只承担队形、距离和运动方向；不要为了补可读性又在原四秒里堆更多切镜。非关键背景活动可以保持连续而不逐项验收。

一段时间若包含接触、发现不对、试探、挣脱、回看等串行动作，即使没有台词，也需要逐拍估算。对白只有两秒，并不能推出其余动作都能在剩下两秒完成。必要时调整镜头入点、删重复核对或重分时间，但保留建立因果所需的信息。

对于轻松的 30 秒双人互动，一个可调整的起排方案是：

| 段落 | 起排时间 | 任务 |
| --- | --- | --- |
| 建立行动与冲突 | 0–6 秒 | 让人物开始做一件具体的事 |
| 交锋与动机累积 | 6–14 秒 | 给关系变化铺前因 |
| 新信息／关系转折 | 14–21 秒 | 收到信息，重新判断，节奏改变 |
| 关键选择或事件 | 21–25 秒 | 完成全场最重要的动作 |
| 事件后的反应 | 25–30 秒 | 让人物的反应完成这场戏 |

这不是固定模板。悲伤可以从慢到更慢；惊吓可以长时间等待后瞬间爆发；冲突升级可以越走越快。8 秒片段通常只容纳一个清晰转折，60 秒也不意味着必须增加台词。

时长改变时重新编排铺垫、转折和回应，不把 15 秒轴机械乘二变成 30 秒。延长后的时间可用于明确关系或保留有任务的沉默，不默认将所有动作慢放。

## 5. 从真人可演性反查

逐段核对：

1. **台词**：按所写语速能说完吗？有没有留换气和对方接话的空间？
2. **路程**：伸手、探身、起身、绕桌、走近分别需要什么起点与过程？不要把跨空间动作写成瞬移。
3. **接触**：递出、接稳、松手，谁先谁后？接触发生后对方有时间反应吗？
4. **感知**：视线已看到关键刺激吗？是否要求角色在知道信息之前改变状态？
5. **情绪**：前后情绪有桥吗？是否把理解、犹豫和决定压进同一个瞬间？
6. **结尾**：关键事件后，观众能看到至少一个有意义的回应吗？若没有，是否有明确的切断意图？
7. **数学**：起止秒数连续，无遗漏、无无意重叠、末端等于目标时长；关键事件占用不超出所在时间段。

不必给每个眨眼计算小数。只给关键停顿大致尺度，如“半拍”“约一秒”，并让整个动作链有足够空间。

## 6. 超预算时如何处理

按剧情损失从小到大尝试：

1. 删除重复解释，让已经可见的动作承担信息。
2. 删除装饰性走位、无作用的表情链和重复镜头。
3. 合并表达同一意图的节拍，保留因果与人物辨识度。
4. 缩小本段事件范围，把一场完整戏聚焦为一个转折。
5. 当上述项被用户锁定，明确指出最短可演版本仍超时，给出延长或分段方案。

不要自动改动用户要求逐字保留的台词；不要把“语速更快”当唯一修复方式。若交付替代方案，标注它改变了哪些约束，不冒充原要求已全部满足。

## 7. 连续性速查

对关键节拍只需记住必要状态：

| 状态 | 核对问题 |
| --- | --- |
| 人物位置与朝向 | 下一个动作从前一段结束位置开始吗？ |
| 视线目标与知情 | 此人看见／听见了什么？尚不知道什么？ |
| 持物与手部 | 道具在谁哪只手里？手是否被占用？ |
| 接触与支撑 | 身体距离是否够得到？移动后如何保持平衡？ |
| 情绪残留 | 上一拍的紧张是否还影响下一拍？ |
| 未完成任务 | 什么没做完，谁在等什么条件？后续继续、改做别事还是暂缓？ |
| 运动阶段 | 动作处于起步、途中、收势还是停稳？下段承接方向与余势，还是错误重启？ |
| 叙事切点 | 本段只能停在哪一步？是否提前完成了应留给后段的接触、通过或揭示？ |
| 镜头与声音 | 切镜或分段是否切断关键反应、动作或一句台词？ |

多段生成时，将必要状态转为每段正文的起始条件和结束条件。是否需要复用尾帧、参考素材或特定音轨，依据平台实际支持和现有素材决定。

## 校核说明的写法

合适：

> 按 30 秒成片粗排，台词约占 6–8 秒；递物与短句部分并行，确认信息、抬头回应依次发生。结尾留 5 秒观察反应。已完成文字层面的时长与连续性校核，实际生成仍可能需要调整。

不合适：

> 已通过真人实拍验证，每个微表情均可由 Seedance 精确到 0.1 秒执行。

没有实际排练或生成证据，就不写相应结论。
