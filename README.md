# Seedance 2.5 人物表演导演

把简短剧情转成动机清楚、动作自然、情绪细腻、时长可演的视频提示词。

这个 Skill 先设计人物为什么行动、情绪怎样通过表演显现、动作需要多少时间，再组装最终提示词。重点适配 Seedance 2.5，也可将表演方法用于其他视频模型，保留用户原有的模型选择。

## 三层设计

| 层次 | 解决的问题 | 产出 |
| --- | --- | --- |
| 剧情与情绪 | 人物为什么这么做？状态为什么改变？ | 行动目标、触发点、情绪路径 |
| 人物表演 | 观众具体看见或听见什么？ | 眼神、嘴角、手部、重心、声音与听者反应 |
| 时间预算 | 台词和动作能否在目标时长内完成？ | 连续时间轴、动作先后、停顿与反应余量 |

例如，“她害羞了”可以被转成一条有前因的表演链：她听到对方的赞赏，没有马上接话，视线先落到桌边，随后看回对方，笑意这时才露出来。另一位人物可以直接回应赞赏，不必复制同样的动作。

细节服务人物与情境。这里不要求每段都“眼神先动”，也不把“前快后慢”套到所有故事上。先建立人物日常的行动节奏，再突出少数关键停顿；面具角色使用其实际可动结构，群像变化检查每个人是否真正接收到了刺激。

优化细微表情时，分别考虑感受强度、外显幅度和控制意图，再写清表情怎样开始、维持、收回或留下余韵。身份稳定应允许正常表情运动；“自然”也可以是坦率的大笑、成功的克制或动画里的明显动作。单一反应按所需短镜头安排，不为凑足 30 秒增加情节。

- [时间与连续性](references/timing-and-continuity.md)：对白粗估、串行与并行动作、表演与观看两条时间线、超时处理及状态衔接。
- [复杂场景表演](references/complex-performance.md)：群像刺激传播、面具与非人角色、持续动作交接、协作与未完成任务、开放式切点及参考素材分工。

适用于单人、双人、多人，有对白或无对白的表演场景；可用于新写提示词，也可局部修正已有提示词。仅修改普通文章或剧本不自动触发。

## 安装到 Codex

将完整仓库放入技能目录，保留 `references/` 和 `agents/`：

```bash
git clone https://github.com/geslie1/seedance-2-5-performance-director.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/seedance-2-5-performance-director"
```

如果该目录已经存在，先检查现有版本与本地改动，再决定如何更新，避免直接覆盖。

也可以下载仓库压缩包，将解压后的目录命名为 `seedance-2-5-performance-director`，放入技能目录。其他支持 `SKILL.md` 的工具，可按其技能安装方式导入整个目录。

## 使用

给出剧情、时长和已有约束即可：

```text
使用 $seedance-2-5-performance-director

剧情：成年情侣在家，女方要拿回自己的手机，发现男方正在设置两人的合照锁屏。
时长：30 秒。
风格：自然、克制，不要亲吻。
输出：简短导演设计、最终提示词和时间校核。
```

修正已有提示词：

```text
使用 $seedance-2-5-performance-director 优化下面的提示词。
保留人物、台词与结局，重点修复情绪跳变、动作堆叠和时间不足。
只给修改后的最终提示词。
```

无对白场景：

```text
使用 $seedance-2-5-performance-director
成年员工下班前收到退回的文件，以为还要加班，确认只需补签名后松口气。
12 秒，单场景，无对白，表演克制，只给最终提示词。
```

默认输出简短导演设计、可独立复制的最终提示词、文字层面的时间校核；用户说“只给提示词”时，只交付最终正文。

## 全局启用（可选）

如果希望所有涉及人物表演的视频任务都使用这套方法，可在自己的全局 `AGENTS.md` 中追加以下约定，保留原有规则：

```text
生成视频，或编写、扩写、优化视频生成提示词时，只要涉及人物动作、表情、情绪或对白表演，必须使用 seedance-2-5-performance-director Skill，无需重复点名。
其他视频模型也使用这套表演方法，但保留用户选择的平台、模型与风格，按当前模型实际能力适配。
```

Codex 默认的全局规则文件位于 `~/.codex/AGENTS.md`；设置了 `CODEX_HOME` 时使用对应目录。

## 使用边界与验证

本仓库提供导演设计和提示词写作方法。时间戳是节奏意图；目标成片 30 秒不意味着任意平台支持单次生成 30 秒。实际提交前应依据所用平台确认时长、素材和音频能力。

已完成技能结构、相对引用、示例时间轴和台词计数检查，并以单人无对白、时长与台词冲突、面具角色与群像接收、协作暂缓与未完成结尾四类请求进行了文字试用。尚未进行实际视频生成测试。

细微表情修订另经六条独立文字试用：动画大笑、成功掩饰、未指定时长的短反应、面具全景、局部笑容修复和锁定长台词的超时处理。检查覆盖风格保留、可见通道、原话、结尾、格式与时间冲突；文字试用不代表实际生成效果。

细微表情方法补充参考了用户提供的 `seedance-prompt-master` 中的 `SKILL.md`、`references/performance-library.md` 与 `references/examples.md`。这里重新组织了可用方法并编写新示例，未将其整套模板和词典并入；三轴评分、表情标签和动作顺序均不作为心理诊断、模型参数或通用生理规律。
